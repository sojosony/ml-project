Machine Learning Model Comparison

Performance evaluation of three machine learning algorithms used for Indian house price prediction.

Linear Regression

A statistical learning algorithm that identifies linear relationships between property features and house prices.

Decision Tree

Uses decision rules and branches to predict property prices based on different property characteristics.

BEST PERFORMING MODEL

Random Forest

Combines multiple decision trees and averages their predictions to improve prediction accuracy and reduce errors.

Performance Comparison Table

Algorithm MAE ↓ RMSE ↓ R² Score ↑

Random Forest ★ 34.04 70.41 0.7761

Graphical Performance Analysis

1. Mean Absolute Error (MAE)

Lower MAE indicates better prediction performance.

2. Root Mean Squared Error (RMSE)

Lower RMSE indicates fewer large prediction errors.

3. R² Score

Higher R² indicates better explanation of price variation.

Final Model Selection

The three machine learning algorithms were evaluated using the same performance metrics.

Random Forest is selected as the final model because it achieved:
  • Lowest MAE: 34.04
  • Lowest RMSE: 70.41
  • Highest R² Score: 0.7761 (77.61%)
Therefore, Random Forest demonstrated the best performance among the three evaluated algorithms on the test dataset and is used for final house price predictions.
